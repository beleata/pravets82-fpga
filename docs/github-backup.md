# GitHub checkpoint — 2026-09-27

Хранилище: https://github.com/beleata/pravets82-fpga (частно).
Release/tag: `checkpoint-2026-09-27`.

В Git се пазят RTL, Pico кодът, Windows приложението, тестовете,
настройките на платката и документацията. `docs/checkpoint/` съдържа
избрани резултати от физическите проверки и кадър от играта.

Release архивът `A2-checkpoint-2026-09-27.zip` съдържа цялото състояние на
директорията A2 към този commit, включително `build/`: готовия FPGA SRAM
образ, build отчети, симулации, външните игрови/ROM данни и техния произход.
Изключени са само `.git`, Python/pytest кешовете и самата директория за архиви.
Манифестът към release-а съдържа commit, размер и SHA-256 на всеки файл;
отделен SHA-256 файл проверява самия ZIP.

SDK, Windows драйверите, Python и GitHub идентификационните данни не са
част от A2 и не са включени. Използваният Supra SDK е описан в
`tools/build_fpga.py`. Външните ROM/игрови данни не получават нов лиценз
чрез това частно архивиране; произходът им остава в `build/karateka`.

## Възстановяване

Клонирай хранилището в нова директория. За точно това състояние избери tag-а
`checkpoint-2026-09-27`, свали ZIP от Releases и го разархивирай в корена
на клонираното хранилище. Пътищата в ZIP са относителни към този корен.
Например `build/fpga/a2_link_sram.prg` трябва да остане на същия относителен път.

Инсталирай зависимостите с `python -m pip install -r host/requirements.txt`.
За локалните unit тестове е нужен и pytest. Кодът за диагностичния анализ
с py65 е отделен и не се използва от Windows приложението.

Готовият SRAM образ позволява възстановяване без повторна компилация,
ако са налични Supra `af.exe`, Altera USB-Blaster драйверът и провереното
окабеляване. Следвай `docs/bring-up.md` и `tools/program_fpga.py`.
Познатата JTAG readback грешка е запазена в отчета; не е обявена за решена.
Функционалността беше проверена отделно през SPI. Flash не е записван.

След програмиране стартирай Pico моста:

```powershell
python host/pico_repl.py --port COM7 --start-bridge --backend pio --spi-hz 2000000 --transport binary
```

После `start-a2.cmd` и бутон Karateka. Записаните файлове не запазват
текущата позиция в играта: хардуерната RAM се губи при изключване.

## Какво е постигнато

- Собствен 6502 във FPGA; пълен Klaus functional test на физическия чип.
- 48 KiB основна RAM и 4 KiB горна банка; екран и клавиатура през Pico.
- Karateka чрез адаптер за конкретната ProDOS версия, без Disk II.
- Физически проверени старт, движение и зареждане на всички игрови файлове.
- Прозорец до 10 кадъра/s, приблизително 9 в последната проверка.
- Няма звук; целият нормален игрови маршрут още не е проверен.
- Снимките на екрана временно спират CPU и забавят изпълнението.

Този checkpoint е следа от работещия прототип; не означава завършена
Apple II съвместимост. Следваща работа — след по-бърз интерфейсен хардуер.
